# Design fonts (optional, recommended)

Drop the following font files here for full design fidelity; they are
loaded automatically at startup (gui/calibration_style.py):

- Geist        (headings)  - SIL OFL 1.1 - https://github.com/vercel/geist-font
- Inter        (body text) - SIL OFL 1.1 - https://github.com/rsms/inter
- JetBrains Mono (data)    - SIL OFL 1.1 - https://github.com/JetBrains/JetBrainsMono

Any .ttf/.otf placed in this folder is registered. Without them the UI
falls back to Segoe UI / Consolas - layout is unaffected.
